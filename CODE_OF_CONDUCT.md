# Code of Conduct

## Commitment

Cab Booking System welcomes participation from people with different backgrounds and experience. We aim to keep project discussion respectful, constructive, and focused on improving the project.

## Expected behavior

- Treat contributors and reviewers with respect.
- Offer and receive technical feedback in good faith.
- Critique code and design without attacking people.
- Respect privacy; do not publish personal, location, account, or payment information.
- Follow the repository's contribution and security guidance.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate intimidation, unwanted sexual attention, doxxing, and disruptive conduct that prevents others from participating are not acceptable in project spaces.

## Maintainer response

The maintainer may remove content, close discussions, or restrict participation to keep collaboration safe and useful. Responses should be proportionate to the behavior.

For a conduct concern, contact the maintainer privately through GitHub [@brajesh31](https://github.com/brajesh31). Do not include private user or driver data in public reports.

## Scope

This policy applies to repository issues, pull requests, reviews, and other project-related spaces, including when someone represents the project publicly. It supports respectful collaboration and does not prohibit good-faith technical disagreement.
