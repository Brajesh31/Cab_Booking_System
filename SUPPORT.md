# Support

## Where to ask

- For reproducible defects or focused proposals, open an issue in the [GitHub repository](https://github.com/Brajesh31/Cab_Booking_System/issues).
- For setup questions, review [Installation](docs/installation.md) and [Troubleshooting](docs/troubleshooting.md).
- For suspected vulnerabilities or sensitive data exposure, follow [SECURITY.md](SECURITY.md) and report privately.
- For conduct concerns, read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact the maintainer through [@brajesh31](https://github.com/brajesh31).

## Include helpful details

Provide the affected route, role, request shape with fake data, Java version, database type, reproduction steps, and redacted error output. Never post passwords, JWTs, real phone numbers, license details, precise locations, or payment information.

## Project scope

This is an individual software prototype, not a commercial taxi platform, dispatch service, payment processor, or emergency service. It has no uptime or response-time commitment. Do not use it to manage real trips or payments in its current state.
