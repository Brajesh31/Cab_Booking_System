# 🖼️ Documentation Assets

Store original architecture drawings, sanitized screenshots, and other project-owned documentation visuals here.

## Rules
- Do not commit screenshots containing real personal information, access tokens, database credentials, or driver licence details.
- Redact request/response samples before saving them.
- Record the source and rights for third-party graphics.
- Prefer editable Mermaid source for technical diagrams.
- Keep images optimized and provide alt text in consuming documentation.
- Never present a conceptual diagram as a screenshot of the running application.

Current editable technical diagrams live in [../diagrams/](../diagrams/).
